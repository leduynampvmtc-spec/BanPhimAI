# Bàn phím AI (Android)

Bàn phím gõ tiếng Việt kiểu Telex, có thanh nút AI: **Sửa lỗi, Lịch sự, Thân thiện, Ngắn gọn, Mở rộng, Dịch → Anh, Dịch → Việt, Hoàn tác** — dùng **Gemini** hoặc **Claude** (API key của chính bạn).

## Tải về
Vào mục **Releases** (cột phải) → bản mới nhất → tải **BanPhimAI.apk** → mở để cài.

## Cài đặt
1. Mở app **Bàn phím AI** → *Mở cài đặt bàn phím* → bật **Bàn phím AI**.
2. *Chọn bàn phím* → chọn **Bàn phím AI**.
3. Chọn Gemini hoặc Claude, dán API key → *Lưu và thử kết nối*.
   - Key Gemini: https://aistudio.google.com/apikey (có gói miễn phí)
   - Key Claude: https://console.anthropic.com/settings/keys (tính phí riêng theo lượng dùng)

## Cách dùng
- Gõ đoạn văn → bấm nút trên thanh tím. Bôi đen một phần thì AI chỉ sửa phần đó.
- Bấm **Gemini ⇄** để đổi AI. Phím **VI/EN** bật/tắt Telex. Giữ phím cách để đổi bàn phím.
- API key chỉ lưu trong điện thoại. Khi bấm nút AI, đoạn văn được gửi tới Google hoặc Anthropic để xử lý — đừng dùng nút AI cho mật khẩu, thông tin nhạy cảm.
